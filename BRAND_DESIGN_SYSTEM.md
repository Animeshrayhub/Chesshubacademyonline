- Trust
- Simplicity
- Quality
- Professionalism
- Confidence

---

# 3. Responsive Philosophy

Desktop First

Design priority:

1. Desktop (1920px)
2. Desktop (1440px)
3. Laptop (1280px)
4. Tablet
5. Mobile

Desktop must never look like a stretched mobile layout.

# 14. Design Rules

- Keep layouts clean.
- Use generous whitespace.
- Avoid repetitive section designs.
- Alternate layouts throughout the page.
- Build trust before asking for conversion.
- Desktop quality is the highest priority.
- Mobile adapts from desktop.
